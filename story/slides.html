How it runs on one GB10

One box. Everything local.

  • VisionQwen3.6 multimodal on vLLM, reads each camera frame
  • 3D sceneDepth Anything builds a point-cloud twin, the obstruction flagged
  • PeopleRT-DETR, so a person walking through is not a false alarm
  • AgentNemoClaw + OpenClaw drive the Slack loop
  • SandboxOpenShell, no outbound network by default

Why it needs this box

A frontier multimodal model, a depth model, and a people detector run together on 128 GB of unified memory, all offline. The same stack on a laptop cannot hold the models or keep up with the cameras.

Local-first, by construction

It can't leak the video, because the sandbox won't let it.

OpenShell sandbox

Blocks outbound network by default. Even if an agent were told to send a clip outside, there is no line to do it. We show it refusing on camera.

Privacy by default

Raw video stays on the box. Only a privacy-safe, face-blurred evidence frame ever reaches the channel. The dataset a site will never ship to a cloud stays put.

This is the reason the product exists: worker video and the model both live on-site, so compliance and privacy are not promises, they are enforced.
